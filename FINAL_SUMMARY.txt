🚀 HOW TO RUN

1. DATABASE SETUP
   mysql -u root -p
   CREATE DATABASE fitness_dashboard;
   USE fitness_dashboard;
   SOURCE database/schema.sql;

2. BACKEND
   cd backend
   mvn clean install
   mvn spring-boot:run

3. FRONTEND
   cd frontend
   npm install
   npm run dev

4. TEST
   Open: http://localhost:5173
   Mobile: 9876543210
   Get OTP and verify
